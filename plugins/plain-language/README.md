# plain-language

Turn a paper into plain language for non-specialists.

- `/plain-language:lay-summary [paper] [form]` writes a lay summary, a press release or a policy brief.
- The `lay-summary` skill keeps the findings accurate (no overstated claims, the main limitation kept) while making them readable at about a 12–14 reading age.

## Install

In Multilo: Settings → Customize → Plugins → Discover, then **plain-language** → Install.
