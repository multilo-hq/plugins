# peer-review

Write a referee report on someone else's paper.

- `/peer-review:review-paper [manuscript]` starts a review: first a summary to confirm, then a structured report.
- The `peer-review` skill covers confidentiality, what to assess, the report's structure and tone.
- The `methods-critic` agent checks the design, methods and statistics on its own and reports concerns with their locations. It only reads.

Many journals restrict AI tools in peer review. Check your journal's policy first; the skill reminds you.

For answering reviewers of your own paper, use Multilo's built-in reviewer-response skill instead.

## Install

In Multilo: Settings → Customize → Plugins → Discover, then **peer-review** → Install.
