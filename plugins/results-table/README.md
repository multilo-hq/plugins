# results-table

Turn a CSV or Excel file into a clean results table for a paper.

- The `results-table` skill reads the data, works out the rows and columns (for example mean ± SD per group), and runs its bundled script to print the table.
- Markdown for the editor, or LaTeX `booktabs` for submission, with a numbered caption above the table.
- One decimal convention per column, dispersion next to every mean, units in the header, significance as footnote symbols.

## Install

In Multilo: Settings → Customize → Plugins → Discover, then **results-table** → Install.
